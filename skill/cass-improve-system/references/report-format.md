# Report format

Generated by `report.py`; the invoking agent adds judgment on top.

```text
# System Review — <period>

Coverage
- sessions discovered/analyzed
- date range
- agents
- projects/workspaces
- skipped/failed coverage

## Executive summary

## High-confidence improvements
### <candidate>
Type:
Destination:
Evidence:
Why it matters:
Proposed improvement:
Confidence:

## Automation candidates

## New skill candidates

## Existing skill improvements

## Global-rule candidates

## Project-specific improvements

## Successful patterns worth preserving

## Low-confidence / watch list

## Do not promote

## Coverage limitations
```

Principles: traceable evidence references (session ref + short excerpt),
never full transcript dumps; sort by expected value × confidence; state
explicitly when nothing strong was found; report-only by default — the
report is returned in-conversation unless the user asked for a file, and
persistent output lives under `~/.agents/state/cass-improve-system/`,
never inside an arbitrary project repo.
